# Reality Breach

Шутер на выживание в смешанной реальности для Meta Quest. Реальная комната становится игровой ареной: на стенах открываются порталы, из которых появляются враги. Отбивайтесь от волн, используйте замедление времени и набирайте очки.

Проект начинался как учебный. В планах — развить его в полноценную игру.

## Что есть в игре

- Смешанная реальность с passthrough: реальная комната остаётся видимой, а её стены используются для появления порталов и врагов.
- Волны с растущим количеством противников и постепенным появлением новых типов врагов.
- Противники ближнего и дальнего боя.
- Бластер с лазерным прицелом, звуками и эффектами выстрелов.
- Способность замедлять время с перезарядкой.
- Бонусы восстановления здоровья и временного усиления урона.
- Счёт, сохранение лучшего результата, главное меню и пауза.

## Устройства

Игра проверена на **Meta Quest 2** и **Meta Quest 3**. Запускается автономно из APK на самом шлеме. Компьютер нужен для сборки и установки APK.

### Подготовка комнаты

Перед запуском настройте комнату в системных настройках шлема:

| Шлем | Подготовка |
| --- | --- |
| Meta Quest 2 | Вручную задайте стены комнаты. |
| Meta Quest 3 | Выполните автоматическое сканирование комнаты. |

Данные стен нужны игре для размещения порталов и появления врагов.

## Установка и запуск APK

Готовый APK пока не опубликован в репозитории и GitHub Releases. Его можно собрать из исходников по инструкции ниже.

1. Подготовьте шлем для установки своих APK: включите режим разработчика по [инструкции Meta](https://developers.meta.com/vr/documentation/unity/unity-env-device-setup/).
2. Подключите шлем к компьютеру по USB и разрешите USB-отладку в шлеме. Для Windows при необходимости установите Oculus ADB Drivers, указанные в той же инструкции.
3. Проверьте подключение и установите APK через ADB:

   ```sh
   adb devices
   adb install -r "path/to/RealityBreach.apk"
   ```

   Замените `path/to/RealityBreach.apk` на путь к собранному файлу. ADB входит в Android SDK и находится в папке `platform-tools`; для этих команд он должен быть доступен из терминала.

4. Откройте игру в библиотеке шлема, в разделе **Unknown Sources / Неизвестные источники**, и выберите **START** в главном меню.

## Сборка из исходников

### Что потребуется

- Unity Hub и **Unity 2022.3.62f3** — версия указана в [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt).
- Модуль **Android Build Support**, включая **Android SDK & NDK Tools** и **OpenJDK**, установленный через Unity Hub. Подробнее — в [документации Unity](https://docs.unity3d.com/2022.3/Documentation/Manual/android-sdksetup.html).
- Git для клонирования репозитория.

### Порядок сборки

1. Клонируйте репозиторий:

   ```sh
   git clone https://github.com/Shovezzz/RealityBreach.git
   ```

2. Добавьте папку `RealityBreach` в Unity Hub и откройте проект в Unity **2022.3.62f3**.
3. Дождитесь импорта ассетов и восстановления пакетов из `Packages/manifest.json`.
4. Откройте сцену `Assets/Scenes/GameScene.unity`.
5. В **File → Build Settings** выберите **Android** и при необходимости нажмите **Switch Platform**.
6. Убедитесь, что `Assets/Scenes/GameScene.unity` включена в **Scenes In Build**. Эта сцена уже указана в настройках сборки репозитория.
7. Для получения APK оставьте **Export Project** и **Build App Bundle (Google Play)** выключенными.
8. Нажмите **Build** и сохраните файл, например как `RealityBreach.apk`. Затем установите его на шлем по инструкции выше.

Описание параметров сборки доступно в [документации Unity 2022.3](https://docs.unity3d.com/2022.3/Documentation/Manual/android-BuildProcess.html).
